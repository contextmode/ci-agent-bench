### Features

- Add `--members` to `deno task` to run a task only in workspace members, not the root ([#35748](https://github.com/denoland/deno/pull/35748))

- Link deno.com/agents.md from `deno --help` ([#36339](https://github.com/denoland/deno/pull/36339))

- Gate constrained-memory cgroup reads in `node:os` ([#36218](https://github.com/denoland/deno/pull/36218))
